# Mouse Loop 桌面版

macOS 全局坐标连点器，可在不同应用之间录制并回放鼠标点击。

## 使用

1. 双击 `dist/Mouse Loop.app`。
2. 首次使用时，在“系统设置 → 隐私与安全性 → 辅助功能”中允许 **Mouse Loop**。
3. 点击“录制一轮”，应用会隐藏；在桌面上按实际顺序点击。
4. 按 `⌘⇧R`，或重新打开应用并点击“完成录制”；应用会重新出现。
5. 检查坐标和每一步之后的间隔，设置循环次数；`0` 表示无限循环。
6. 点击“隐藏窗口并开始”。运行中可按 `⌘⇧S` 紧急停止。

## 稳定性功能

- 新录制的步骤会绑定目标 App 和窗口内相对坐标；移动窗口后仍可定位，目标窗口不存在时自动暂停。
- 自动忽略 Dock、菜单栏、通知中心和 Mouse Loop 自身的点击，避免结束录制时产生多余步骤。
- “智能等待”会记录目标附近的画面颜色，播放时最多等待 12 秒，画面匹配后才点击。首次开启需要在“系统设置 → 隐私与安全性 → 屏幕录制”中允许 Mouse Loop，并重启应用。
- Dock 图标角标显示“当前轮次·当前步骤”。所有步骤的最小安全间隔为 100ms。

录制配置保存在 `~/Library/Application Support/MouseLoop/steps.json`。

## 限制

- 旧版配置仍使用屏幕绝对坐标；用 1.3 重新录制后会改用目标窗口相对坐标。
- 目标窗口必须处于可见状态，最小化窗口不能按坐标点击。
- 屏幕锁定、Mac 睡眠或关机后无法继续点击。
- 仅在你有权自动化的软件中使用。
