# 网页坐标连点器（Chrome 扩展）

按设定的可视区域坐标和等待时间，在当前网页中循环点击。关闭扩展弹窗、切换标签页或最小化浏览器后，任务仍会留在目标页面中运行。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹 `mouse`。
5. 建议把扩展固定到工具栏。

如果扩展刚安装或刚在扩展管理页重新加载，已经打开的旧网页可能尚未载入执行脚本。当前版本会自动注入；若页面仍提示无法连接，刷新一次游戏网页即可。

## 使用

1. 打开目标网页，点击扩展图标。
2. 直接填写每一步的 X、Y 坐标和“本步完成后”的等待毫秒数；或点击“录制一轮点击操作”。
3. 录制时正常操作网页：每次点击既会执行原操作，也会记录坐标，实际等待时间也会自动记录。使用顶部的“完成录制”“撤销一步”和“取消”按钮控制录制；内嵌网页和游戏 iframe 也支持录制。
4. 最后一次点击后先等待你希望的循环间隔，再点击“完成录制”；这段时间就是最后一步到下一轮第一步的间隔。
5. 重新打开扩展检查或微调坐标与间隔。循环次数填 `0` 表示无限循环。
6. 点击“保存并开始”。要停止时回到同一网页，打开扩展并点击“停止”。

录制中的步骤会暂存在 Chrome 会话存储里，即使比赛加载期间扩展后台休眠也不会丢失。完成录制后，步骤会一直保留到点击“保存并开始”。

## 能力边界

- 坐标基于网页可视区域，不是屏幕绝对坐标。运行期间请不要改变窗口尺寸、页面缩放或滚动位置。
- 浏览器最小化后可继续派发网页 DOM 点击，不会移动真实鼠标，也不能点击 Chrome 工具栏、下载框、系统窗口或其他应用。
- Chrome 会限制后台页面的定时器精度，因此非常短的间隔在最小化时可能被延迟。
- 合成点击的 `isTrusted` 为 `false`；出于安全原因，文件选择器、支付、权限弹窗及部分网站会拒绝这类点击。
- 页面刷新或跳转会停止当前任务，需要重新点击“开始”。Chrome 内部页面（例如 `chrome://`）不允许扩展运行。

仅在你有权自动化的网站上使用，并遵守网站条款。
